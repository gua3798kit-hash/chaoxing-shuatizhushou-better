# 学习通刷课助手

本项目基于学习通刷课助手 **1.0.10 版本**进行优化（同样需要搭配油猴插件），保留原有课程任务处理功能，并改进大模型答题、图片题识别和答案填写逻辑。

原项目：[DaRin1403/xuexitong-autostudy](https://github.com/DaRin1403/xuexitong-autostudy)。本项目保留原作者的版权声明，依据 [MIT 许可证](LICENSE)发布。
## 主要优化

- 优化了原版 DeepSeek 接入和模型配置的问题。
- 优化了原版误填模型思考内容的问题。
- 优化了原版无法识别部分图片题的问题。
- 优化了原版多图题处理可能中断的问题。
- 优化了原版重复作答覆盖已有答案的问题。
- 优化了原版多空题漏填、错位的问题。
- 优化了原版简答计算题格式不清晰的问题。
- 优化了原版公式出现 LaTeX 源码的问题。
- 优化了原版图片读取不完整时继续作答的问题。
- 优化了原版作业页跑完流程后无法重新运行的问题。
- 优化了原版模型下拉框可能只显示部分模型的问题。
- 优化了原版日志面板可能执行外部返回内容中 HTML 的问题。
- 优化了原版切换平台后图片题仍请求 deepseek-flash 的问题。
- 优化了原版 OpenAI 推理模型因参数不兼容请求失败的问题。
- 优化了原版使用其他平台接口时缺少访问授权声明的问题。
- 新增了互评页辅助评分：AI 按答案生成建议分，由人逐题检查后手动提交。
- 将脚本的更新地址改为本仓库。

## 推荐模型

图片题需要使用支持**图像输入**的大模型：

- **DeepSeek 官方 API**：推荐图片题使用 `deepseek-flash`。使用官方接口时，脚本会自动为图片题选择该模型；纯文字题继续使用配置的文字模型。
- **其他视觉模型**：可考虑支持图像输入的千问等模型。使用时需配置对应平台的 API Key、接口地址和模型名称，不同平台的兼容性需要自行测试。
- **其他平台的图片题模型**：在“图片题视觉输入”下方填写该平台支持图像输入的模型名；留空则使用上方的 AI 模型。

## 安装与使用

1. 在浏览器中安装 Tampermonkey。
2. 打开本仓库中的 `.user.js` 文件，点击 **Raw**，按提示安装。
3. 打开学习通页面，进入脚本设置。
4. 启用 AI 答题，配置 API Key、接口地址和模型。
5. 需要识别图片题时，开启“图片题视觉输入”。
6. 作业页答题结束后，可点击面板上的 ↻ 重新运行；已有答案的题会保留，作答过程中无法重新运行。
7. 进入互评页后，点击“生成建议分”获取建议分，逐题检查后手动提交。

## 注意事项

- AI 答案可能有误，提交前请自行检查。
- 调用模型 API 可能产生费用。
- 接口地址需填写以 `/chat/completions` 结尾的 OpenAI 兼容地址；首次访问脚本未内置的地址时，Tampermonkey 会弹窗询问，允许后才能使用。
- 图片题的文字和图片会发送至所配置的模型服务。
- 在互评页点击“生成建议分”后，题目、参考答案和学生作答（含图片）会发送至所配置的模型服务。
- 互评建议分可能有误，脚本不会自动提交，请逐题检查。
- 部分无法读取的图片需要人工处理。
- 本版本经过本地模拟测试，实际页面兼容性仍需验证。
- 使用脚本可能违反平台或学校的相关规定，请自行评估。
